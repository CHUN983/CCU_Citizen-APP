### 測試架構

#### 單元測試模式
```python
# Pattern 1: Mock Database
@patch('services.xxx_service.get_db_cursor')
def test_function(mock_get_cursor):
    mock_cursor = MagicMock()
    mock_get_cursor.return_value.__enter__.return_value = mock_cursor
    # Test logic...

# Pattern 2: FakeCursor
def test_function(monkeypatch, service):
    cursor = FakeCursor(fetchone_results=[data])
    patch_cursor(monkeypatch, service, cursor)
    # Test logic...
```

#### Mock 數據最佳實踐
```python
# ✅ 完整的 Mock 數據
{
    'id': 1,
    'content': 'Content with at least 10 chars',  # 符合驗證
    'created_at': '2025-10-24 10:00:00',
    'updated_at': '2025-10-24 10:00:00',  # 必須包含
    'is_deleted': False
}
```
