## 🔧 主要變更說明

### 1. 類別 6: 意見投票測試（合併）

**變更前**:
- 測試類別 6: 意見投票測試 (TC-OPIN-007~009)
- 測試類別 8.6: 投票切換功能測試 (TC-VOTE-001~005)

**變更後**:
- **測試類別 6: 意見投票測試**
  - 基本投票功能 (TC-OPIN-007~009)
  - 投票切換功能 (TC-VOTE-001~005)

**理由**: 投票切換是投票功能的增強，應歸入同一類別

### 2. 類別 9: 個人意見管理測試

**變更**: 8.5 → 9

**理由**: 升格為獨立類別，與意見建立、查詢等平級

### 3. 類別 10: 意見互動限制測試

**變更**: 8.7 → 10

**理由**: 這是橫跨多個功能（投票、留言、收藏）的限制測試，應獨立分類

### 4. 類別 11-15: 審核系統測試

**變更**: 9~13 → 11~15

**理由**: 順延編號，騰出 9、10 給意見管理系統測試
