# 📱 手機端使用指南

## 快速開始（3 步驟）

### 1️⃣ 連接 VPN
```
開啟學校 VPN 應用程式
連接到校園網路
```

### 2️⃣ 訪問網站
```
打開瀏覽器（Chrome/Firefox/Edge）
輸入：https://140.123.105.199:8443
```

### 3️⃣ 信任證書（首次使用）
```
看到安全警告 → 點擊「進階」→ 點擊「繼續前往」
完成！
```

## 📲 安裝為 PWA（推薦）

安裝後可以像原生 App 一樣使用！

### Chrome

1. 打開網頁後，點擊右上角 **⋮** (三點選單)
2. 選擇 **「加到主畫面」**
3. 點擊 **「安裝」**
4. ✅ 完成！應用程式圖示會出現在主畫面

### Edge

1. 打開網頁後，點擊右下角 **…** (三點選單)
2. 選擇 **「新增至主畫面」**
3. 輸入名稱（如：市民意見平台）
4. 點擊 **「新增」**
5. ✅ 完成！

### Firefox

1. 打開網頁後，點擊網址列旁的 **📱** 圖示
2. 或點擊右上角 **⋮** → **「安裝」**
3. 點擊 **「新增至主畫面」**
4. ✅ 完成！

## 💡 常見問題

### Q: 為什麼會顯示「不安全」警告？

**A**: 這是因為我們使用自簽名證書（校內專用）。在 VPN 環境下是安全的，點擊「繼續」即可。

### Q: 需要每次都信任證書嗎？

**A**: 不用！**只需要第一次信任**，之後就會自動記住。

### Q: 沒有連 VPN 可以用嗎？

**A**: 不行。必須連接學校 VPN 才能訪問伺服器（140.123.105.199）。

### Q: PWA 和網頁有什麼差別？

**A**:
| 功能 | 網頁 | PWA |
|------|------|-----|
| 全螢幕 | ❌ | ✅ |
| 主畫面圖示 | ❌ | ✅ |
| 離線使用 | ❌ | ✅ |
| 推送通知 | ❌ | ✅ |
| 啟動速度 | 普通 | 快 |

### Q: 如何解除安裝 PWA？

**Android**:
```
長按主畫面的 App 圖示
→ 拖曳到「解除安裝」
或
設定 → 應用程式 → 市民意見平台 → 解除安裝
```
